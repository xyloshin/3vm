# Weather app illustration

The public page shows one prompt branching into three mobile weather app designs.

> Design a simple weather app.

The three directions are Calm, Bold, and Immersive. They use the same fictional Lisbon weather content to make comparison easy.

![Weather app directions](../assets/weather-app.png)

## How this illustration was made

The maintainer used the built-in image-generation tool to generate this single promotional graphic, specifying the branching layout, three mobile screens, shared weather content, and three visual directions. The displayed short prompt summarizes the concept; it is not the complete image-generation instruction. The owner selected the colourful version for the public page.

This is an illustration of the workflow, not a recorded run of an independently installed skill. The actual skill asks for three separate mockup images, short tradeoffs, and a recommendation. The composite arranges three concepts together for the README.

The weather values are fictional. These static images do not demonstrate working interactions or validated usability. The separate [reading-list example](reading-list.md) retains the earlier three-image demonstration and its generation prompts.
